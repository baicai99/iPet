# 小程序样式定义规范（纯样式层）

> 目标：任何人只要写样式，**必须且只能**按本规范执行。

---

## 1. 单位与尺寸定义

### 1.1 基础单位

* **统一使用 ****`rpx`** 作为布局与尺寸单位
* 禁止在样式中出现以下单位：

  * ❌ `vw` / `vh`
  * ❌ `rem`
  * ❌ `%`（除非是宽度自适应场景）

#### 允许场景

| 场景       | 允许单位                  |
| -------- | --------------------- |
| 宽高、间距、圆角 | `rpx`                 |
| 字体       | 由 Typography Mixin 决定 |
| 图片自适应    | `%`（仅限 `width`）       |

---

## 2. 页面与容器

### 2.1 页面根节点

* 页面背景色统一由 `page` 选择器控制
* 禁止使用 `body` / `html`

```scss
page {
  background-color: $app-background;
}
```

---

### 2.2 页面主容器

* 页面最多允许 **一个主滚动容器**
* 禁止嵌套多个滚动源

```scss
.page {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}
```

---

## 3. 布局规则

### 3.1 Flex 布局

* 默认使用 Flex
* 禁止使用 CSS Grid
* 禁止依赖 `height: 100%` 进行高度传递

```scss
.container {
  display: flex;
  flex-direction: column;
  gap: 24rpx;
}
```

---

### 3.2 定位

* 禁止滥用 `position: fixed`
* 吸底区域必须通过布局占位实现

```scss
.footer {
  margin-top: auto;
}
```

---

## 4. 滚动定义

### 4.1 页面滚动

* 默认使用页面原生滚动
* 禁止在页面根节点使用 `overflow: hidden`

---

### 4.2 局部滚动

* 必须使用 `scroll-view`
* 高度必须为显式值（`rpx` / 计算后值）

```scss
.scroll-area {
  height: 600rpx;
}
```

---

## 5. 字体与文本

### 5.1 字体来源

* 字体样式**只能通过 Typography Mixins 定义**
* 禁止硬编码 `font-size` / `font-weight`

```scss
.title {
  @include text-title-2;
}
```

---

### 5.2 文本规则

* 必须显式定义行高（由 mixin 提供）
* 多行省略优先降级为单行

---

## 6. 颜色与背景

### 6.0 变量体系（强制约束）

* **禁止使用 CSS 变量（Custom Properties）**

  * ❌ `--xxx`
  * ❌ `var(--xxx)`
* **只允许使用 Sass 变量**（编译期展开）

  * ✅ `$app-*`
  * ✅ 其他项目级 Sass 变量

> 说明：样式中不得出现任何 CSS 变量定义或引用，避免运行期差异与小程序兼容问题。

### 6.1 颜色来源

* 所有颜色必须来自 Sass Token
* 禁止出现硬编码颜色值

```scss
.card {
  background-color: $app-card-bg;
  color: $app-text-primary;
}
```

---

## 7. 图标与图片

### 7.1 图标

* 禁止远程 `@font-face`
* 图标必须为本地资源或组件

---

### 7.2 图片

* 图片路径必须为相对路径
* 必须显式指定适配模式

---

## 8. 交互态样式

### 8.1 点击态

* 禁止使用 `:hover`
* 统一使用 `:active`

```scss
.button:active {
  background-color: $app-active-bg;
}
```

---

## 9. 样式作用域

### 9.1 scoped 规则

* 页面组件允许 scoped
* 禁止 scoped 作用于 `page`

---

### 9.2 第三方组件

* 禁止使用深度选择器作为主方案

---

## 10. CSS 黑名单（强制）

### 10.1 选择器黑名单

| 禁止项               |
| ----------------- |
| `> *`             |
| `> *:last-child`  |
| `:nth-child(n+3)` |

---

### 10.2 特性黑名单

* ❌ `filter`
* ❌ `backdrop-filter`
* ❌ 远程 `@font-face`
* ⚠️ `position: sticky`

---

## 11. 设计系统 Token 使用

### 11.1 允许使用

* `$app-*` Sass 变量
* Typography Mixins

---

### 11.2 禁止使用

* `var(--*)`
* CSS Variables

---

## 12. 代码示例（合规样式）

```scss
.page {
  min-height: 100vh;
  background-color: $app-background;
}

.card {
  background-color: $app-card-bg;
  border-radius: 24rpx;
  padding: 24rpx;
}

.title {
  @include text-headline;
}
```

---

> 本规范只允许**追加，不允许弱化或随意破例**。
>
> 任何不在此文档中的样式写法，默认视为**不合规**。
