## 二、认证登录模块 (P0)

### 2.1 登录页面

**功能描述**：管理员登录入口，独立于普通用户认证体系。

**UI 组件**：
- [x] 用户名输入框
- [x] 密码输入框（带显示/隐藏切换）
- [x] 登录按钮
- [x] 登录状态提示（成功/失败）
- [x] 登录失败计数器展示（3次后锁定30分钟）

**API 调用**：
```
POST /api/admin/login
```

**交互规则**：
1. 登录成功后跳转至仪表盘页面
2. Token 存储于 `sessionStorage`（启动时迁移旧的 `localStorage` 数据）
3. 登录失败显示具体错误信息（账号不存在/密码错误/账号锁定）
4. 支持 "记住我" 功能（可选）
5. 登录页文案统一使用中文

**安全要求**：
- 密码输入支持显示/隐藏切换
- 登录防爆破提示（显示剩余尝试次数）
- Token 过期自动跳转登录页

## 三、系统初始化向导 (P0)

**功能描述**：首次接入后台时的初始化向导，引导完成后端连接、入口路径与管理员创建。

**布局规则**：
- 主卡片采用双栏布局：左侧主任务（约 2/3），右侧辅助说明（约 1/3），顶部基线对齐。
- 当前步骤需展示一句话摘要（例如“检测后端连通性并保存 API 地址”）。
- 操作区收敛到主卡片 Footer，主按钮为“保存并下一步”或“完成初始化”。
- 入口路径步骤采用“自动生成/手动填写”二选一模式，端口与长度归入高级设置折叠区。
- 最终登录地址作为结果卡展示，提供复制入口。

**交互规则**：
1. 首步包含后端连通性检测与 API 地址设置。
2. “刷新检测”为次要操作按钮，不与主 CTA 并列抢权重。
3. 当前生效信息以只读形式展示（当前 API 地址、Mock 状态）。
4. 入口路径校验结果在右侧辅助区提示，不重复展示最终地址。
5. 新增确认信息步骤，展示入口路径、登录地址、管理员信息等关键参数并提供一键复制。
6. 确认页提醒用户截图保存或粘贴到备忘录。

- [x] 用户名输入框

- [x] 校验提示与保存反馈

**API 调用**：
```
GET /api/admin/settings
PUT /api/admin/settings
```

**权限要求**：登录管理员可访问

**交互规则**：
1. 页面加载时拉取设置并填充表单，密码不回显
2. 密码为空时不更新密码，修改密码需输入旧密码并验证通过
3. 保存时进行校验，成功后提示并刷新显示值
4. 入口路径更新后需提示并跳转至新登录地址
5. 取消操作恢复上次保存值，重置操作重新拉取最新配置
