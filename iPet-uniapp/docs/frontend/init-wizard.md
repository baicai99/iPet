# 管理后台初始化向导规范

## 规范背景
初始化向导是后台首次可用的入口页面，用户需要在短时间内完成配置并获取可保存的登录地址。本规范用于统一信息架构、文案与交互，避免页面复杂度提升导致可信度下降。

## 适用对象
- 后台管理端初始化向导页面与相关交互
- 负责产品、设计、前端实现的协作者

## 约束规则
- 目标在 3 分钟内完成初始化并拿到可保存的后台登录地址
- 仅保留一个主 Card 容器，主表单与辅助说明分区展示
- 三步向导主内容区一次只展示当前步骤表单
- 规则提示跟随表单项，提交时强校验，输入中轻提示
- 同日变更使用同一版本号并更新 Changelog

## 目标与验收标准
- 用户在 3 分钟内完成初始化
- 第 2 步可获得可点击、可复制、可保存的登录地址
- 表单输入区域无重复信息或噪音卡片
- 操作区固定在底部，移动端单列展示
- 错误提示统一为一句话问题 + 修正方向

## 信息架构线框（低保真）
```text
顶部：Steps（3 步）

主区（一次只展示当前步骤）
┌────────────────────────┬───────────────────────┐
│ 主表单（当前步骤）       │ 辅助说明（轻量）       │
│                         │ - 2~3 行说明           │
│                         │ - 关键提示/目标        │
└────────────────────────┴───────────────────────┘

底部固定操作区：上一步 / 下一步 / 完成初始化
```

## 步骤内容边界与文案

### Step 1：欢迎
字段
- 无

提示文案
- 主提示：欢迎使用管理后台，完成初始化后可获得可保存的登录入口。

### Step 2：入口路径
字段
- 路径输入
- 随机生成（可指定长度 1-16）
- 端口（可选，可随机）
- 最终后台登录地址（可点击、可复制、提示保存）

提示文案
- 主提示：入口路径是后台的专属入口，建议使用随机生成以提升安全性。
- 规则提示：1-16 个字符，仅小写字母/数字，且以字母开头
- 端口说明：非标准端口才需要填写
- 随机端口：可一键生成 1024-65535 之间的端口
- 登录地址标题：最终后台登录地址
- 保存提示：请保存该地址，初始化完成后只通过此地址访问后台。
- 空态：请先完成入口路径设置

错误提示
- 路径格式不正确：路径格式不正确，请检查规则
- 端口非法范围：请输入 1-65535 的端口
- 随机长度非法：请输入 1-16 的长度

### Step 3：创建管理员
字段
- 用户名
- 邮箱
- 密码
- 确认密码

提示文案
- 主提示：创建首个管理员账户，用于管理系统与配置。
- 轻提示：请确保邮箱可用，密码建议至少 8 位。
- 密码规则提示：必须包含大小写字母、数字与符号

错误提示
- 用户名过短：用户名至少需要 3 个字符
- 邮箱格式错误：请输入有效的邮箱地址
- 密码过短：密码至少需要 8 个字符
- 密码规则不满足：需包含大小写字母、数字与符号
- 两次密码不一致：两次输入不一致，请重新确认

## 交互与状态说明
- 交互流程（简图）
```text
Step1 欢迎
   ↓
Step2 生成入口路径 + 端口 + 获取登录地址（可复制）
   ↓
Step3 创建管理员
   ↓
完成初始化（成功提示，等待用户手动前往登录）
```
- 后端连接检测：进入页面即检测后端可达性，未连接时显示提示卡片并禁用“下一步/完成初始化”
- 初始化完成后禁止访问 `/init`，若再次打开将自动跳转到登录页
- 下一步按钮：当前步骤校验通过时可用，否则禁用
- 提交加载：完成初始化按钮 loading 状态
- 成功状态：完成后显示结果页与处理中提示，保留在当前页等待用户点击操作
- 复制反馈：复制成功提示“登录地址已复制”，失败提示“复制失败，请手动复制”

## 错误提示文案表
| 字段 | 常见错误 | 提示文案 |
| --- | --- | --- |
| 入口路径 | 格式错误 | 路径格式不正确，请检查规则 |
| 端口 | 非法范围 | 请输入 1-65535 的端口 |
| 随机长度 | 非法范围 | 请输入 1-16 的长度 |
| 用户名 | 少于 3 字符 | 用户名至少需要 3 个字符 |
| 邮箱 | 格式错误 | 请输入有效的邮箱地址 |
| 密码 | 少于 8 字符 | 密码至少需要 8 个字符 |
| 密码 | 规则不满足 | 需包含大小写字母、数字与符号 |
| 确认密码 | 不一致 | 两次输入不一致，请重新确认 |
| 后端连接 | 未连接 | 未检测到后端服务，请先配置后端连接 |

## 响应式与可用性验收
- 手机：单列布局，底部操作条固定，辅助说明折叠或缩短为 2-3 行
- 平板：主表单 + 辅助说明并排，保持 7:3 视觉比例
- 桌面：主卡容器宽度上限，避免拉伸影响阅读
- 键盘可操作，焦点顺序与步骤一致
- 错误提示紧贴字段，避免散落

## 上线后补强（可选）
- 初始化完成后提供“配置入口”可再次查看/修改入口路径
- 增加复制成功反馈与二次确认，避免复制失败无感知
- 可选埋点：每一步完成率、停留时长、失败原因 Top
