# Mini Chart 日级聚合规范

## 规范背景

当前 mini 折线图用于展示指标的近期趋势。若同一天存在多条记录，直接按“记录条数”取样会导致点位密度异常、趋势误读，因此需要统一日级聚合口径。

## 适用对象

- 指标卡片上的 mini 折线图（`trend_line`）
- 使用 `buildChartData` 构建的 mini 图表数据

## 约束规则

- 聚合粒度为“天”，以本地日期为准。
- 同一天多条记录时，仅保留当天最后一条记录（latest by timestamp）。
- 仅保留最近 7 天内的聚合点（最多 7 个点）。
- 最近 7 天内无记录的日期不生成点，保持图表当前渲染策略。

## 示例

输入（同一天两条记录）：

- 2025-12-25 09:00 = 20kg
- 2025-12-25 21:00 = 21kg

输出（折线图点位）：

- 2025-12-25 = 21kg
