### 1.4 错误码规范

#### HTTP 状态码
```
200 OK - 请求成功
201 Created - 创建成功
204 No Content - 删除成功
304 Not Modified - 资源未修改
400 Bad Request - 请求参数错误
401 Unauthorized - 未授权，需要登录
403 Forbidden - 权限不足
404 Not Found - 资源不存在
409 Conflict - 资源冲突（如重复提交）
422 Unprocessable Entity - 业务逻辑错误
429 Too Many Requests - 请求频率限制
500 Internal Server Error - 服务器错误
502 Bad Gateway - 网关错误
503 Service Unavailable - 服务不可用
```

#### 业务错误码 (code)
```typescript
// 通用错误 (1xxxx)
10000 - 成功
10001 - 未知错误
10002 - 参数错误
10003 - 请求频率限制

// 认证错误 (2xxxx)
20001 - Token 无效
20002 - Token 过期
20003 - Refresh Token 失效
20004 - 登录失败（邮箱或密码错误）
20005 - 用户不存在
20006 - 账号已被禁用

// 权限错误 (3xxxx)
30001 - 无权限访问
30002 - 资源不属于当前用户
30003 - 游客模式限制（需升级账号）

// 资源错误 (4xxxx)
40001 - 资源不存在
40002 - 资源已删除
40003 - 资源已过期
40004 - 资源冲突（如重复创建）

// 业务错误 (5xxxx)
50001 - 宠物数量达到上限
50002 - 健康记录不存在
50003 - 数据同步失败
```

**错误处理策略**:
- HTTP 401 自动触发 Token 刷新

- 业务错误码优先显示 `message` 字段


### 4.2 签名验证

#### 签名生成 (后端)
```typescript
import crypto from 'crypto';

const generateSignature = (payload: string, secret: string): string => {
  return crypto
    .createHmac('sha256', secret)
    .update(payload)
    .digest('hex');
};

// 请求头
headers['X-Webhook-Signature'] = `sha256=${generateSignature(
  JSON.stringify(payload),
  webhookConfig.secret
)}`;
```

#### 签名校验 (接收方)
```typescript
const verifySignature = (
  payload: string,
  signature: string,
  secret: string
): boolean => {
  const expectedSignature = `sha256=${generateSignature(payload, secret)}`;
  return crypto.timingSafeEqual(
    Buffer.from(signature),
    Buffer.from(expectedSignature)
  );
};
```
