# 用户管理 UI 规范补充

## 规范背景
用户管理页面承担检索与运营操作，需要在可扫读与可操作之间平衡密度、排序与状态表达一致性。

## 适用对象
- 后台管理端用户管理模块（列表页/详情抽屉）

## 约束规则
- 角色标签使用中性样式，状态标签使用语义色（正常=绿，封禁=红，待审核=黄）。
- 表格需提供密度切换（紧凑/舒适），默认紧凑。
- 表格提供排序能力：至少包含宠物数与最近活跃。
- 分页器需要显示总条数与当前范围，并支持每页条数切换（10/20/50）。
- 表格支持多选，出现批量操作条并提供批量封禁/解封/软删除。
- 空状态需区分“无数据”与“无匹配结果”，并提供清除筛选入口。

## 示例
- 角色标签：`游客`、`注册用户` 使用灰色中性标签。
- 状态标签：`正常`=绿色，`封禁`=红色。
- 分页文案：`共 120 条，当前 1-10`，并提供每页条数组合。
